# Contributing

Thanks for helping improve PGCB Power Demand Forecasting.

## Development Workflow

1. Create a focused branch for your change.
2. Create and activate a Python 3.10 or 3.11 virtual environment.
3. Install dependencies with `pip install -r requirements.txt`.
4. Run `python -m py_compile PGCB_Forecasting/app.py`.
5. Launch the dashboard and verify the affected view with the prepared artifacts.
6. Keep generated files, credentials, and local environments out of commits.

## Pull Requests

Describe the problem, the change, and how it was validated. For model changes, include the data source, split strategy, metrics, and relevant assumptions. Avoid committing private or redistributed data without confirming its provenance and usage rights.
